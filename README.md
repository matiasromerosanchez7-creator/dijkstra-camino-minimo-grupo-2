# dijkstra-camino-minimo-grupo-2
# Problema del camino mínimo - Algoritmo de Dijkstra (Grupo 2)

Programa con interfaz gráfica que resuelve el problema del camino mínimo
en grafos dirigidos y sin ciclos de 7 a 16 nodos, mostrando paso a paso
cada iteración del algoritmo de Dijkstra.

Archivo principal: CODIGO FINAL MATEMATICA_COMPUTACIONAL.py

Requisitos: Python 3, networkx y matplotlib
    pip install networkx matplotlib

Ejecución:
    python "CODIGO FINAL MATEMATICA_COMPUTACIONAL.py"
